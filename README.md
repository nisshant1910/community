# Stratzy Discourse theme v0.3

## Update an existing install
1. On GitHub, upload these files over the old ones (same paths, they overwrite).
2. Discourse: Admin > Customize > Themes > open the Stratzy theme > "Check for updates" > update.
3. Reload your preview (?preview_theme_id=...). The logged-out hero shows in a private window.

## Admin tips that complete the look
- Category icons and colors: Admin > Categories > edit each category > set an icon and color.
- Search field in the header: Admin > Settings, search "search experience".
- Rename "New Topic" to "Ask a question": Admin > Customize > Site texts, search "New Topic".
- Upload the supplied Stratzy logo files only. Do not redraw or recolor the logo.
