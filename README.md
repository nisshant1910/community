# Stratzy Discourse theme (v0.1)

Light-only theme on the Stratzy brand system. Fonts: DM Sans, DM Mono (numbers and timestamps), Libre Baskerville italic (`.stratzy-accent`, one phrase per page).

## Install on the TEST community
1. Push this folder to a private Git repo.
2. Admin > Customize > Themes > Install > From a git repository. Add the repo URL (and deploy key if private).
3. Open the theme, set it as default, and select the "Stratzy Light" color scheme.
4. Upload the supplied Stratzy logo files only (Admin > Config > Branding). Do not redraw or recolor the logo.

## Move to the ORIGINAL community later
Install the same repo URL there. Nothing else carries over; categories and settings come from the checklist.

## Notes
- If you turn on Content Security Policy, allow fonts.googleapis.com and fonts.gstatic.com or self-host the fonts.
